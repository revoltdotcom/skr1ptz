## Install

`~/.zshrc` is a symlink to `zshrc.zsh` in a checkout of this repo. An edit here applies to the next shell, or to the current one after `z`.

```bash
git clone git@github.com:revoltdotcom/skr1ptz.git ~/git/skr1ptz
mv ~/.zshrc ~/.zshrc.bak   # ln -s won't replace an existing file
ln -s ~/git/skr1ptz/zshrc.zsh ~/.zshrc
exec zsh
```

Requirements:

- [Oh My Zsh](https://ohmyz.sh) in `~/.oh-my-zsh`.
- `git`, which the first start uses to clone the [zi](https://github.com/z-shell/zi) plugin manager into `~/.zi`.
- Optional: `colordiff` (for `diff`) and `source-highlight` (for syntax highlighting in `less`), both from Homebrew. Each is used only when it's installed.

## What `zshrc.zsh` sets up

Startup runs in this order:

1. **Oh My Zsh** with a random theme and the `git` plugin. Updates install every 7 days, without a prompt.
2. **History**: 250,000 entries with timestamps, shared between open shells. Commands that start with a space aren't recorded, and older duplicates are dropped.
3. **Editing**: vi key bindings and `EDITOR=vim`.
4. **`PATH`**, rebuilt from scratch, so entries added earlier (for example by `/etc/zprofile` or `~/.zprofile`) are dropped. In order, with duplicates removed:
   1. `~/.local/bin` and `~/bin`
   2. `/opt/homebrew/opt/openjdk/bin` (Homebrew OpenJDK)
   3. `/opt/homebrew/bin`, on Apple Silicon only (detected with `uname -m`, not from the macOS version)
   4. `/usr/local/bin`, `/usr/bin`, `/bin`, `/usr/sbin`, and `/sbin`
5. **Aliases and functions**, listed below.
6. **zi**, initialized. This file loads no plugins through it.
7. **Local overrides** from `~/.zshconfig/*.zsh`. See [Local overrides](#local-overrides).
8. Clears the screen.

It also sets `AWS_PROFILE=default`, sets `NODE_EXTRA_CA_CERTS` when `~/.certs/SystemRootCertificates.pem` exists, and sets `UV_NATIVE_TLS` and `UV_SYSTEM_CERTS` (the two lines marked `# ADDED BY IRU`).

### Git

| Command | What it does |
|---|---|
| `gp [-F] [ARGS]` | `git push ARGS`. Refuses when the checked-out branch is `main` or `master`, unless `-F` is the first argument. |
| `gpsup [-F] [ARGS]` | Pushes the current branch to `origin` and sets it as the upstream. Same guard as `gp`. |
| `gres` | Checks out the default branch, then pulls if the checkout succeeded. |
| `prune [-f]` | Fetches with `--prune`, then deletes local branches whose upstream is gone. If the current branch is one of them, switches to the default branch first. Without `-f`, git keeps branches it doesn't consider merged, which includes squash-merged ones. |

The guard checks the checked-out branch, not the refspec: `gp origin main` run from another branch still pushes your local `main`. Oh My Zsh's other push aliases, such as `gpf!` and `ggpush`, aren't guarded.

## Local overrides

Machine-specific settings, and anything that shouldn't be committed, go in `~/.zshconfig/*.zsh`. These files load after everything above, so they can add to `PATH` or redefine aliases. `zc` reloads them.

## Tools (`bin/`)

Documented in [`bin/README.md`](bin/README.md). `bin/` isn't on `PATH` by default. Run the tools by path, or add `path+=(~/git/skr1ptz/bin)` to a `~/.zshconfig` file.

- **`substack-mirror`**: mirrors a Substack publication's posts to Markdown files (Python and pandoc).
